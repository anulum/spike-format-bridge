# Support

Contact Miroslav Šotek through www.anulum.li or protoscience@anulum.li.

For repository-check failures, include the command, exit code, finding code,
repository revision and relevant tool versions. The conversion library is still
planned; existing recording formats are not yet advertised as supported.

Share minimal, legally distributable inputs when reporting a parsing problem.
Do not send confidential recordings, credentials or identifying subject data
through a public issue.
