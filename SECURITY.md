# Security reporting

The repository is at architecture-only maturity. Its local metadata and source
provenance commands are the current input surfaces; recording codecs and public services are
not available.

Send sensitive reports privately to protoscience@anulum.li. Include the affected
revision, command, input class and observed behaviour without publishing secrets
or confidential recordings. Miroslav Šotek coordinates triage and any disclosure.

The checks read bounded local files and report authored finding codes. Source
provenance uses native Git with filesystem-monitor execution disabled.
Development dependencies and filesystem permissions remain part of the host
trust boundary. A passed declaration check is not a security certification.
