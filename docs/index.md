# Spike Format Bridge

This documentation covers the current repository foundation and planned
recording-conversion boundary.

Spike Format Bridge is part of the **SC Neuromorphic Computing Systems** group (SC-NEUROMORPHIC-COMPUTING-SYSTEMS). The [group and project map](https://github.com/anulum/sc-neurocore/blob/main/docs/ecosystem.md) shows the whole programme and where this repository sits in it.

The commands check local declarations, source provenance, workflow policy, exact
installed tools, documentation and inventory, with explicit preflight aggregation. See
[validation tooling](validation-tooling.md) for its interface and native Python
documentation, and [architecture](ARCHITECTURE.md) for component ownership.
